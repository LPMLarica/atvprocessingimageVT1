1. Objetivo

Este projeto implementa um programa em Python para converter imagens coloridas para escala de cinza utilizando três métodos distintos: Average, Luminosity e Desaturation.

2. Explicação dos Métodos

Average Method

Fórmula: (R + G + B) / 3

Todos os canais recebem o mesmo peso.

Luminosity Method

Fórmula: 0.21R + 0.72G + 0.07B

Considera a percepção humana da luz.

Desaturation Method

Fórmula: (max(R,G,B) + min(R,G,B)) / 2

Baseado na diferença de intensidade das cores.

3. Trecho Principal do Código

def luminosity_method(r, g, b): return int(0.21 * r + 0.72 * g + 0.07 * b)
